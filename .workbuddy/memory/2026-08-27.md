## Bug 修复记录（预设功能）

### 选择预设后面板内容不更新
- **时间**: 2026-08-27 11:01
- **现象**: 在面板中选择预设后，骨骼属性值不更新
- **根因**: `preset_enum_update` 回调使用 `handlers.load_post.append(delayed_load)` 延迟执行，但 `load_post` 是 Blender **文件加载后**回调，只在打开 .blend 文件时触发，用户选择预设时**不会**触发，导致 `load_preset` 从未执行
- **修复**: 改用 `bpy.app.timers.register()` 注册一次性定时器（first_interval=0.01 下一帧执行），执行后自动移除；模块级变量 `_preset_load_timer` 管理句柄，快速切换预设时先注销旧定时器防止堆积；unregister 时清理
- **验证**: 语法检查通过

### 切换预设控制台持续输出对称骨骼填充失败
- **时间**: 2026-08-27 11:03
- **现象**: 切换预设时控制台持续输出 `自动填充对称骨骼失败 (left_eye_bone): cannot access local variable 'symmetric_bone'`
- **根因**: `try_fill_symmetric_bones` 中当 `mode` 既不是 `'EDIT_ARMATURE'` 也不是 `'POSE'`（如 OBJECT 模式）时，`symmetric_bone` 局部变量从未被赋值，后续 `if not symmetric_bone` 访问导致 `UnboundLocalError`。预设加载 timer 在下一帧执行，用户处于非编辑/姿态模式时每个对称骨骼属性都会触发该错误
- **修复**: 初始化 `symmetric_bone = None`，并为非编辑/姿态模式添加 `else: return False` 分支
- **验证**: 语法检查通过

### 合并骨骼操作符 RNA 解析警告刷屏
- **时间**: 2026-08-27 11:07
- **现象**: 控制台持续输出 `unable to get Python class for RNA struct 'OBJECT_OT_merge_selected_bones_weights'`（每帧多条）
- **根因**: 上一改动让 `OBJECT_OT_merge_selected_bones_and_weights` 继承了**已注册的 operator** `OBJECT_OT_merge_selected_bones_weights`。Blender RNA 系统不支持 operator 继承已注册 operator 的模式，UI 每次重绘（每帧）解析该 RNA 结构时失败并刷警告
- **修复**: 提取未注册基类 `OBJECT_OT_merge_selected_bones_base`（包含 poll/execute/also_merge_bones 全部逻辑），两个具体 operator 都直接继承该基类，不再互相继承
- **验证**: 语法检查通过

### 备份清理操作符 NoneType 错误
- **时间**: 2026-08-27 11:07
- **现象**: `OBJECT_OT_cleanup_backups.execute` 报 `AttributeError: 'NoneType' object has no attribute 'name'`
- **根因**: 遍历 `bpy.data.objects` 时，空物体（Empty）等对象的 `data` 属性为 `None`，`obj.data.name` 直接崩溃
- **修复**: 先取 `obj_data = obj.data` 并判断 `obj_data is not None` 再访问 `.name`
- **验证**: 语法检查通过
